# 🛠️ Tecnologias e Ferramentas Utilizadas — Projeto Sonora

Este projeto foi desenvolvido utilizando tecnologias modernas amplamente utilizadas no mercado, com foco em **desenvolvimento de APIs escaláveis, infraestrutura em nuvem, sistemas de busca e containerização**.

---

## 💻 Linguagem de Programação
- **Java** — Linguagem principal utilizada no desenvolvimento do backend da aplicação.

---

## ⚙️ Frameworks Backend
- **Spring Boot** — Framework principal para construção da API REST e estrutura do sistema.
- **Spring Web** — Desenvolvimento de endpoints REST.
- **Spring Data JPA** — Camada de persistência e integração com banco de dados.
- **Spring Validation** — Validação de dados nas requisições da API.

---

## 🗄️ Banco de Dados
- **MySQL** — Banco de dados relacional utilizado no projeto.
- Banco de dados hospedado na nuvem da :contentReference[oaicite:0]{index=0}.
- Persistência de dados utilizando **JPA / Hibernate**.

---

## 🔎 Sistema de Busca
- **Elasticsearch** — Utilizado para:
  - Indexação de dados
  - Otimização de buscas
  - Melhor performance em consultas de eventos e artistas

---

## ☁️ Cloud Computing
Infraestrutura hospedada na nuvem utilizando serviços da :contentReference[oaicite:1]{index=1}:

- **EC2** — Hospedagem da aplicação backend.
- **S3** — Armazenamento de arquivos e mídias da plataforma.
- **MySQL em cloud** — Banco de dados da aplicação.

---

## 📦 Containerização e DevOps
- **Docker** — Utilizado para:
  - Containerização da aplicação
  - Padronização do ambiente de desenvolvimento
  - Facilidade de deploy
  - Execução isolada dos serviços
